Job Tracker — Production Architecture

React 19 + Django REST Framework + Postgres • Free-tier deployment on Vercel, Render, and Neon

Frontend (Vercel)

  • • React 19 + TypeScript 5 + Vite 7
  • • Tailwind CSS 3 utility classes
  • • Axios with 401-interceptor logout
  • • 8-line auth gate keeps hooks tidy
  • • VITE_API_URL baked in at build time

Backend (Render)

  • • Django 5.1 + DRF + gunicorn
  • • TokenAuthentication on /api/jobs/*
  • • ViewSet filters by request.user
  • • Migrate-on-boot via Start Command
  • • HSTS, secure cookies, throttling

Database (Neon)

  • • Postgres 16, serverless, pooled
  • • TLS with channel_binding=require
  • • JobApplication.owner is non-null FK
  • • Data migration before schema change
  • • Free tier: 0.5 GB storage
